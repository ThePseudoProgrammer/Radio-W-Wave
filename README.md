https://thepseudoprogrammer.github.io/Radio-W-Wave/

Сайт для проекта «Radio W-Wave» — современная веб-страница для музыкального онлайн-радио. Полностью адаптивная верстка, выполненная в соответствии с требованиями Pixel Perfect и методологией БЭМ. Уделено внимание семантике и доступности для всех пользователей. Сайт оптимизирован для различных устройств и браузеров, обеспечивая комфортное использование.
